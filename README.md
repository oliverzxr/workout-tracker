# Workout Tracker

Aplicação de acompanhamento de treinos em desenvolvimento.

## Objetivo

Registrar treinos, séries, repetições e cargas, permitindo
acompanhar o desempenho e a progressão ao longo do tempo.

## Funcionalidades implementadas

- Contagem de séries por treino
- Cálculo do volume de carga
- Testes automatizados com Node.js

## Executar os testes

node --test

## Tecnologias

- JavaScript
- Node.js
