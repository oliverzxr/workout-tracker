# Release v1.0.0

## Notas preparadas

- Treinamento completo em português, com rotinas, registro de séries e RIR, descanso, histórico editável, recordes e progressão.
- Catálogo local de 76 movimentos, com aliases, filtros e fichas técnicas. Demonstrações em dois quadros para 28 exercícios.
- PWA instalável, rascunho offline, armazenamento local, backup JSON restaurável e histórico CSV.

A candidata para aprovação é `1.0.0-rc.2`. O backup JSON continua no formato 1 e os dados salvos no mesmo endereço permanecem disponíveis. Ao trocar de endereço, leve os dados pelo backup antes de começar a registrar em produção.

## Publicação após aprovação

1. Confirmar a aprovação visual e funcional e CI verde no commit candidato.
2. Ajustar os manifestos npm para `1.0.0` e integrar a candidata à `main` preservando o histórico.
3. Validar a CI da `main`. Selecionar GitHub Actions como fonte do Pages e executar manualmente **Publicar portfólio no GitHub Pages** na `main`.
4. Verificar a URL HTTPS publicada, o manifesto, os ícones, o service worker, as demonstrações offline, backup e restauração. Validar a adição à Tela de Início em um iPhone físico.
5. Criar a tag `v1.0.0` sobre o commit validado e publicar a release com estas notas, capturas e documentação. Guardar o commit de origem do deploy para reversão.

O workflow publica apenas o build da aplicação em `dist`. GitHub Pages é a opção preparada para portfólio e uso pessoal. Uma operação comercial exigirá uma hospedagem que aceite SaaS e revisão de privacidade, domínio e política de backups antes da migração.
