# Auditoria de licença do projeto

## Código do Workout Tracker

O manifesto desta candidata declara `"license": "ISC"` desde o primeiro commit examinado. A árvore revisada não contém um arquivo de licença raiz com aviso de copyright e texto completo para o código próprio. O campo `"private": true` restringe a publicação via npm. A visibilidade pública permite o uso das funções de visualização e fork do GitHub pelos termos da plataforma. O alcance da licença sobre todo o código merece confirmação do titular antes de oferecer permissões públicas específicas a terceiros. [Referência da licença ISC](https://opensource.org/license/isc-license-txt) · [Licenciamento no GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

Quando concedida, a licença ISC permite uso, cópia, modificação e distribuição com ou sem remuneração, desde que o aviso de copyright e o texto de permissão acompanhem as cópias. A ISC inclui limitação de garantias e não exige a publicação de modificações. Esta auditoria registra o estado observado. A definição formal de titularidade e da licença pública fica com o proprietário do projeto.

## Componentes distribuídos

React, React DOM, idb, lucide-react e Zod têm avisos permissivos próprios. O build também inclui código do Workbox sob MIT e Inter sob SIL OFL 1.1. Os avisos acompanham a aplicação e devem continuar no artefato de deploy. A licença tipográfica disciplina redistribuição e alterações da fonte separadamente do código.
